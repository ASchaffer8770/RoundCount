Core features

Built for the range,
not the boardroom.

Live Sessions

Real-Time Logging

Start a live session at the range and log runs as you go. Track rounds fired, range time, and malfunctions in real time — then review summaries per firearm.

Analytics

Meaningful Data

Dashboard analytics that answer real questions: total rounds, malfunctions per 1k, top firearms by usage, ammo consumption. 7D / 30D / 90D / 1Y filtering on every chart.

Gear Setups

Setup Tracking

Create setups per firearm — optic, light, grip, and gear configs — and link them to sessions. Know exactly what you were running when you set a personal best.

Malfunctions

Failure Logging

Log and categorize every malfunction. Track failure rates per firearm over time. Reliability metrics built for shooters who actually care about their data.

Onboarding

Coach Mark Walkthrough

First-time users get contextual overlays that highlight key UI elements and explain the workflow. Replayable anytime from Settings.

Privacy

Local-First Storage

Everything lives on your device. No account signup. No cloud sync. No analytics tracking. Open the app, log your session, close it. That's it.

Pro Feature

UPC Barcode
Scanning

Point your camera at any factory ammo box. RoundCount looks up the caliber, grain weight, bullet type, brand, quantity, and case material automatically. Results are cached on-device for instant re-scans.

Pro Feature

Auto-Decrement
Inventory

Enable inventory tracking per ammo product. When you end a live session, rounds are automatically deducted. If a session would put you below zero, RoundCount asks if you restocked before finalizing.
